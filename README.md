One line, under 200 characters, of the excuse a dog gives after being caught eating the homework. A model judge reads the entries two at a time and keeps the funnier one.

## Run it

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt` (deterministic, same bytes every run).
